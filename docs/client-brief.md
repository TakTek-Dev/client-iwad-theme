## أولاً: هوية المنصة

- **الاسم:** إيواد (IWAD) — المنصة الرقمية لمعهد دراسات الحرب.
- **الجمهور:** (أ) عسكريون ومهتمون عاديون من الطبقة الوسطى والدنيا — الأولوية، (ب) نخب ومثقفون متخصصون، داخل سوريا وخارجها.
  - **النتيجة التصميمية:** يُقرأ بسهولة لغير المتخصص + مصداقية أكاديمية تقنع الباحث.
- **الاختصاص:** بحث وتعليم في النظريات والعقائد والفكر العسكري إقليمياً وعالمياً — وليس تفاصيل تكتيكية/عملياتية. قسما «عقائد» و«إرث عسكري» بصياغة تحليلية-تاريخية-أكاديمية، لا كأدلة تشغيلية.
- **الطبيعة:** مؤسسة خاصة غير ربحية ومستقلة.

### خطوط حمراء

1. لا صور أو أسماء شخصيات رسمية منسوبة لدولة — لا في الفريق ولا الشركاء.
2. لا ألوان/رموز/زخارف توحي بانتماء حزبي أو طائفي — الهوية تُقرأ كمركز بحثي محايد (حرج جداً لقسم «إرث عسكري»).
3. «تعليمي» يُطلق كمحتوى معرفي فقط، مع بنية قابلة للتوسع لاحقاً نحو تدريب رسمي.

## رابعاً: الأقسام

### 1. الرئيسية
الهدف: بناء الثقة فوراً — الزائر يفهم خلال ثوانٍ.
العناصر: Hero (أهم مادة/تقدير عاجل) · شبكة أحدث الإصدارات مقسمة بالأقسام (كل قسم بلونه) · شريط أفقي متجدد لآخر التقديرات · بطاقات تعريف الأقسام · تعريف مختصر بالمعهد → «عن المعهد» · نموذج النشرة · تغذية سوشيال.

### 2. عالمي
رصد وتحليل التوازنات العالمية. بنية «محاور قوى» ثابتة (أمريكا-الصين، روسيا-أوروبا/الناتو، آسيا-المحيط الهادئ…) كل محور صفحة تجمع مواده (نمط Chatham House).
زوايا: سباقات التسلح، توازن القوى، الحرب السيبرانية، التحالفات الدفاعية.
**ميزة:** خريطة عالمية تفاعلية «ساكنة» (تُحدَّث دورياً، ليست بثاً حياً — مفهوم ISW كأداة تنقّل وشرح فقط) تقود لصفحات المحاور.

### 3. إقليمي
ملفات دائمة: سوريا-إسرائيل، سوريا-إيران، مصر-إفريقيا، أفغانستان، لبنان-إسرائيل، تركيا-إسرائيل + قابلية إضافة.
كل ملف = Hub: خلفية تاريخية، خط زمني، كل المواد المرتبطة، الباحثون المتخصصون (نمط «الملفات» عند الجزيرة/معهد الدوحة).
**ميزة:** خريطة إقليمية تفاعلية — كل دولة/زوج علاقات قابل للنقر → صفحة الملف.

### 4. عقائد
شرح أكاديمي للمفاهيم (الحرب الخاطفة، عقيدة المقاتل…) كمواضيع بحثية تُقارن تاريخياً ونظرياً — لا خطوات تنفيذية (نمط King's College War Studies).
**الميزة الأبرز:** معجم المصطلحات العسكرية — قاعدة قابلة للبحث، كل مصطلح تعريف موجز + صفحة تفصيلية، مرتبط أوتوماتيكياً بالمواد التي تستخدمه. أداة عمل للباحثين.

### 5. تعليمي
إعداد باحثين ونشر وعي. الإطلاق: أدلة «كيف تبدأ كباحث عسكري»، قوائم قراءة، شرح مبسط، مقالات تأسيسية. المعجم مرجع مشترك.
صيغة «حوار مع باحث» شهرية (نص أولاً، صوت/فيديو لاحقاً — روح معهد الحرب الحديثة West Point).
**مستقبلاً (الـIA تحجز مكانه فقط):** «مسار المتدرب» بدورات ومقاييس تقدم.

### 6. إرث عسكري
معارك وتكتيكات إسلامية وغير إسلامية بصياغة تاريخية-أكاديمية محايدة.
قالب «ملف معركة»: سياق تاريخي، القوى، سير المعركة (سردية لا تعليمات)، القيادات، الأثر والدلالة.
تصنيف بالحقب: الفتوحات المبكرة / الأموي والعباسي / المملوكي والعثماني / الحروب الصليبية / معارك عالمية / الحديث.
**ميزة:** خط زمني عسكري تفاعلي عبر القرون — أداة التصفح الرئيسية للقسم.
إضافي: بطاقات «في مثل هذا اليوم» للسوشيال، ملفات القادة عبر التاريخ.
**ملاحظة:** طابع أرشيفي/موسوعي، ليس خطابياً أو احتفالياً.

## خامساً: مشتركات

- بحث متقدم وفلاتر: القسم، المنطقة، الحقبة، نوع المادة، الباحث.
- صفحات الباحثين: سيرة أكاديمية/مهنية فقط، بلا انتماءات رسمية (نمط معهد واشنطن).
- فعاليات وندوات: قسم مستقل.
- تحميل PDF لكل مادة طويلة/موسعة.
- نشرة بريدية مدمجة في كل صفحة تقريباً.
- مشاركة سوشيال بنقرة من كل مادة.
