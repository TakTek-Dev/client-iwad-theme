## ٠. القرار التصميمي الحاكم

**الشخصية:** مجلة أكاديمية محكّمة، مش موقع إخباري.
Flat design صارم: زوايا شبه قائمة، مفيش جرادينتس، مفيش ظلال ثقيلة، الجريد المربع (من اللوجو الكوفي) هو الأساس الهندسي لكل التكوين.

**اختبار كل شاشة:** «هل تُقرأ بسهولة لغير المتخصص، وبمصداقية تقنع الباحث؟» — لو لأ، ارجع.

### خطوط حمراء (من العميل + البراند بوك) ❌

1. **ممنوع أيقونات قتالية:** سيوف، بنادق، رتب، دروع، طائرات حربية — الهوية بحثية
2. **ممنوع صور/أسماء شخصيات رسمية** منسوبة لدولة — في أي مكان
3. **ممنوع ألوان أو رموز** توحي بانتماء حزبي/طائفي — خصوصاً قسم «إرث عسكري»
4. **قسم إرث عسكري:** طابع أرشيفي/موسوعي محايد — مش خطابي ولا احتفالي
5. **قسم تعليمي:** محتوى معرفي فقط في الإطلاق — البنية تسمح بتوسع لاحق لتدريب رسمي

## ٢. التايبوجرافي

### الخط

**PF DIN Text Arabic** — خط الهوية الأصلي (DIN العربي)، self-hosted من `assets/fonts/web/*.woff2` عبر `assets/css/fonts.css`. أوزان: 300 / 400 / 500-600 / 700-900 (الميديم بيخدم 600، البولد بيخدم 900).

```css
:root {
  --font-main: 'PF DIN Text Arabic', 'Segoe UI', Tahoma, -apple-system, sans-serif;
}
```

- preload للوزنين 400 و700 في `<head>`
- ممنوع الرجوع لأي Google Font عربي — الهوية بخطها الأصلي
- اللوجوتايب لا يُكتب بخط أبداً — SVG فقط

### السلم (Arabic-first)

العربي يحتاج حجم أكبر قليلاً و line-height أعلى من اللاتيني:

| Token | Size | LH | Weight | الاستخدام |
|---|---|---|---|---|
| `--fs-xs` | 13px | 1.6 | 400 | تواريخ، ميتا |
| `--fs-sm` | 14px | 1.7 | 400/500 | بادجز، تسميات، فوتر |
| `--fs-base` | 17px | 1.8 | 400 | **نص المقالات** |
| `--fs-md` | 19px | 1.7 | 500 | مقدمات، اقتباس |
| `--fs-lg` | 22px | 1.5 | 600 | h4 / عنوان كارت |
| `--fs-xl` | 26px | 1.45 | 600 | h3 |
| `--fs-2xl` | 32px | 1.4 | 700 | h2 / عنوان قسم |
| `--fs-3xl` | 40px | 1.3 | 700 | h1 داخلي |
| `--fs-4xl` | 48px | 1.25 | 700 | Hero (ديسكتوب فقط؛ موبايل 32-36) |

### قواعد قاطعة

- `letter-spacing: 0` دايماً — **ممنوع tracking على العربي**
- طول السطر: 60–70 حرف عربي (`max-width: 65ch` تقريبي — اضبط بصرياً)
- الأرقام: **غربية (0-9)** في كل الموقع — إحصاءات، تواريخ، ترقيم. متوافق مع الطابع البحثي (نمط معهد الدوحة). لو العميل طلب هندية (٠-٩) = تغيير موضعي، اسأل قبل الإطلاق
- الكلمات اللاتينية داخل النص العربي (أسماء، اختصارات): نفس الخط — Plex فيه لاتيني متناغم، مفيش تبديل فونت

## ٣. المسافات والجريد

### سلم المسافات (قاعدة 4px)

```css
--sp-1: 4px;  --sp-2: 8px;   --sp-3: 12px;  --sp-4: 16px;
--sp-5: 24px; --sp-6: 32px;  --sp-7: 48px;  --sp-8: 64px;
--sp-9: 96px;
```

- Padding الكروت: `--sp-5`
- بين العناصر داخل الكارت: `--sp-3`
- بين السكاشن: `--sp-8` ديسكتوب / `--sp-7` موبايل
- هوامش الصفحة: 20px موبايل / 40px تابلت+

### الحاويات والنقاط

```css
--container: 1240px;   /* max-width, margin-inline auto */
```

| Breakpoint | | |
|---|---|---|
| Base | ≤767px | عمود واحد، برجر منيو |
| `--bp-md` | ≥768px | عمودين، نافبار كامل |
| `--bp-lg` | ≥1024px | 3 أعمدة، سايدبار المقال |
| `--bp-xl` | ≥1440px | تباعد أوسع فقط — مفيش أعمدة زيادة |

الجريد: CSS Grid، 12 عمود على lg، gap `--sp-5`.

### الزوايا والحواف — هوية الجريد المربع

```css
--radius-sm: 3px;   /* أزرار، إنبتس، بادجز */
--radius-md: 6px;   /* كروت */
--radius-lg: 10px;  /* مودالز، صور Hero — الحد الأقصى */
```

**ممنوع** زوايا أدوَر من 10px — بتكسر صرامة الهوية. **ممنوع** دواير ديكورية عائمة. صور الباحثين مربعة بزوايا `--radius-md`، **مش دايرة**.

### الظلال — شبه معدومة (Flat)

```css
--shadow-none: none;                          /* الافتراضي */
--shadow-raise: 0 1px 3px rgb(26 26 26 / 8%); /* كروت hover فقط */
--shadow-modal: 0 8px 32px rgb(26 26 26 / 16%);
```

العمق بالبوردر والتباين اللوني، مش بالظل.

## ٤. الحركة (Motion 3 — خفيف)

```css
--dur-fast: 150ms;   /* hover, focus */
--dur-base: 250ms;   /* توسعات، تابات */
--dur-reveal: 350ms; /* دخول عند السكرول */
--ease-out: cubic-bezier(0.25, 0.75, 0.4, 1);
```

- Scroll reveal: opacity 0→1 + translateY 12px→0. **Vanilla عبر IntersectionObserver** — مفيش GSAP إلا لو ظهرت حاجة معقدة (التايم لاين مثلاً)
- عنصر واحد لكل viewport يتحرك — مش كل حاجة
- hover الكروت: بوردر يتلون بلون القسم + `--shadow-raise` — **مفيش** scale ولا رفع كبير
- `prefers-reduced-motion: reduce` → كل الحركة off، المحتوى ظاهر فوراً
- المحتوى مرئي بدون JS (no-JS fallback) — السيو أهم من الافكت

## ٥. مواصفات الكومبوننتس

### الهيدر

- Sticky، خلفية `--bg` مع بوردر سفلي `--border` (مفيش شفافية/بلور)
- RTL: اللوجو يمين، القائمة بعده، البحث + «عن المعهد» شمال
- اللوجو: النسخة المزدوجة (`Logo-04` شفاف → SVG)، ارتفاع 44-52px، مساحة آمنة ⅕ الارتفاع
- الرابط النشط: بوردر سفلي 3px بلون قسمه + وزن 600
- موبايل: برجر → درج من اليمين، فيه البحث فوق
- بحث: أيقونة تفتح أوفرلاي / صفحة الأرشيف

### طبقات المحتوى — ٣ قوالب كروت (نظام العميل)

| الطبقة | الكارت |
|---|---|
| **مادة موسعة** | كارت كبير: صورة غلاف 16:9، بادج القسم، بادج «بحث معمّق»، العنوان `--fs-lg`، مقتطف سطرين، الباحث + التاريخ + وقت القراءة، أيقونة PDF |
| **دراسة متوسطة** | كارت قياسي: صورة، بادج القسم، عنوان، الباحث + التاريخ |
| **تقدير موقف** | كارت مضغوط **بدون صورة**: بوردر يمين 3px بلون القسم، بادج «تقدير موقف»، عنوان `--fs-md`، تاريخ. يعيش في شريط أفقي متجدد (Swiper) |

صفحة المادة الموسعة تشمل: جدول محتويات لاصق (سايدبار على lg)، وقت قراءة، زر PDF بارز، سيرة الباحث في الآخر، اقتباسات بارزة (بوردر ذهبي يمين + `--fs-md`).

### بادج القسم

```
خلفية لون القسم · نص كريمي · --fs-sm وزن 500 · radius-sm · padding 4px 12px
```

دايماً ظاهر على أي كارت — الزائر يعرف المادة من أي قسم قبل ما يقرأ.

### كارت الباحث

صورة مربعة (radius-md) · الاسم 600 · تخصص سطر واحد · لينك للصفحة الفردية.
سيرة أكاديمية فقط — **ممنوع** ذكر انتماءات رسمية لدول.

### معجم المصطلحات (ميزة قسم عقائد)

- المصطلح داخل المقالات: underline منقّط ذهبي → tooltip بالتعريف الموجز + لينك لصفحة المصطلح
- صفحة المعجم: بحث فوري + فلترة أبجدية، كل مصطلح كارت
- صفحة المصطلح: تعريف + المواد المرتبطة أوتوماتيك

### التايم لاين (ميزة إرث عسكري)

- عمودي على موبايل، أفقي قابل للسحب على ديسكتوب (Swiper free-mode)
- محطات = مربعات بلون السيبيا على خط `--border`
- تجميع بالحقب: الفتوحات المبكرة / الأموي والعباسي / المملوكي والعثماني / الحروب الصليبية / معارك عالمية / الحديث
- **طابع أرشيفي:** خلفية بيج، صور بفلتر sepia خفيف، ممنوع أي طابع احتفالي

### الخرائط (عالمي + إقليمي)

- SVG ثابت تفاعلي (hover + click) — **مش** خريطة حية
- ألوان: حدود `--border`، تعبئة بيج، المحاور النشطة بلون القسم
- click → صفحة المحور/الملف
- موبايل: الخريطة تتحول قائمة روابط (الخريطة progressive enhancement)

### النشرة البريدية

حقل إيميل واحد + زر — inline في الفوتر + سكشن في الرئيسية.
الزر: خلفية نبيتي، نص كريمي. Placeholder مش بديل عن label (label مخفي بصرياً `.sr-only`).

### الأزرار

| النوع | الشكل |
|---|---|
| Primary | خلفية `--primary`، نص `--on-primary`، radius-sm، padding 12px 24px |
| Secondary | بوردر 1.5px نبيتي، نص نبيتي، خلفية شفافة |
| PDF | Secondary + أيقونة تحميل، البوردر ذهبي `--accent`، النص `--accent-text` |
| Ghost | نص فقط + سهم ←، للـ «اقرأ المزيد» |

الحد الأدنى للمس: **44×44px**. `cursor: pointer` على كل قابل للنقر.

### الفوتر

خلفية `--iwad-ink`، نص كريمي. ٤ أعمدة (lg): اللوجو المؤسسي الكامل (`Logo-07` نسخة فاتحة) + نبذة / روابط سريعة / الأقسام / النشرة + سوشيال. تحت: حقوق + سياسة الخصوصية.

## ٦. قواعد RTL — إلزامية

1. `<html lang="ar" dir="rtl">`
2. **Logical properties فقط:** `margin-inline-start`، `padding-inline-end`، `inset-inline-start`، `text-align: start` — ممنوع left/right في الكود إلا للعناصر الثابتة اتجاهياً
3. أيقونات الأسهم بتتعكس: «التالي» يشاور شمال. Font Awesome: استخدم `fa-arrow-left` كـ«تالي» أو اعكس بـ `transform: scaleX(-1)` مع dir
4. Swiper: `dir="rtl"` على الحاوية — بيدعمه أصلياً
5. الأرقام والكلمات اللاتينية جوة النص العربي: سيبها للـ bidi algorithm، لو اتكسرت لفّها بـ `<bdi>`
6. النصوص المستقبلية الإنجليزية: البنية بتتقلب أوتوماتيك لأننا logical — مفيش CSS تاني

## ٧. الصور والأيقونات

- **الأيقونات:** Font Awesome (أو Lucide SVG) — خطية stroke موحدة. **راجع الخطوط الحمراء §٠** — مفيش أيقونات قتالية أبداً. بدائل: بحث=عدسة، استراتيجية=رقعة شطرنج/بوصلة، عقائد=كتاب، إرث=عمود أثري/مخطوطة، عالمي=كرة أرضية، إقليمي=خريطة
- **ممنوع إيموجي كأيقونات**
- الصور: WebP + `loading="lazy"` تحت الفولد + `width/height` صريحين (CLS)
- صور المقالات: خرائط تاريخية، مخطوطات، أرشيف، تكوينات هندسية مجردة من الهوية — **مفيش** صور أسلحة حديثة لامعة ولا شخصيات رسمية
- fallback لصورة الغلاف: تكوين هندسي من مربعات الهوية بلون القسم + نقطة ذهبية
